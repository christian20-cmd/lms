RENDERING:
  Avant: CoursDetailScreen.build() 
		 → Tap module 
		 → Navigator.push() 
		 → ModuleDetailScreen.build()
		 (2 build cycles, page transition)

  Après: CoursDetailScreen.build() 
		 → Tap module 
		 → setState() 
		 → CoursDetailScreen.build() (liste complète)
		 (1 build cycle, pas de transition)

✅ Impact: Rendu plus fluide, pas de freezing


API CALLS:
  Avant: modulesProvider() → CoursDetailScreen
		 contenusProvider() → ModuleDetailScreen (au push)

  Après: modulesProvider() → CoursDetailScreen
		 contenusProvider() → chaque _ModuleExpansionCard (au expand)

✅ Impact: Contenus chargés on-demand (optimisé)
